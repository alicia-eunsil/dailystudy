# 회화 커리큘럼

개인 학습용, 중상급(B2 지향) 회화. 공식 CEFR 등급 판정 콘텐츠는 아닙니다.
하루 3문장과 설명 하나만 보내며, 일상·여행·업무를 섞어 익숙한 단어로 의도와 뉘앙스를 전달하는 연습을 합니다.

| 주 | 월 | 화 | 수 | 목 | 금 |
|---|---|---|---|---|---|
| 1 | 말 꺼내기 | 진짜 이유 | 부드러운 반대 | 의미 확인 | 응용 복습 |
| 2 | 일정 여유 | 변경과 대안 | 조건부 동의 | 확답 미루기 | 응용 복습 |
| 3 | 불편 설명 | 해결책 제안 | 진행 확인 | 실수 수습 | 응용 복습 |
| 4 | 예상과 실제 | 경험 기반 조언 | 과거의 선택 | 경험 이야기 | 응용 복습 |

## 선정 기준

- 대화 중 바로 말할 수 있는 완결된 문장. 문어적인 도치나 어려운 어휘 자체를 목표로 삼지 않습니다.
- 축약형을 자연스럽게 사용하고, 일상적 구동사와 여러 상황에 응용할 수 있는 문형을 포함합니다.
- 한국어는 문법 형태를 복사하기보다 실제 의도를 전달합니다.
- 설명은 세 문장 가운데 핵심 표현을 하나 중심으로 짧게 정리합니다.
- 금요일은 그 주 문형을 다른 상황에 다시 적용합니다. 메일 길이와 문장 수는 같습니다.

## 참고 자료의 역할

아래는 학습 구성과 추후 콘텐츠 검토에 활용할 자료입니다. 현재 60문장은 이 프로젝트용으로 직접 작성한 예문이며, 아래 기관의 원문을 인용·번역한 자료 또는 공식 인증 콘텐츠가 아닙니다.

- [British Council 문법](https://learnenglish.britishcouncil.org/free-resources/grammar): 수준별 문법 설명 참고.
- [VOA Let's Learn English](https://learningenglish.voanews.com/p/5644.html): 생활 장면을 연결하는 방식 참고. 초급 문장 자체를 본 과정 난이도 기준으로 삼지 않습니다.
- [VOA English in a Minute](https://learningenglish.voanews.com/z/3619): 회화 표현과 관용구 탐색.
- [BBC Learning English](https://www.bbc.co.uk/learningenglish): 주제별 듣기와 대화 상황 탐색.
- [Tatoeba 활용 안내](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus): 추후 예문 후보 검색. 직접 재사용할 때는 문장 ID, 작성자, 링크, 라이선스를 함께 기록하고 음성은 별도 조건을 확인합니다.

새 예문을 추가할 때는 자연스러운 대화인지, 다른 상황에 응용할 수 있는지, 한국어 뜻과 문법 설명이 정확한지 검토합니다. 자동 검사는 구조와 발송 동작을 확인하며 언어 전문가 검수를 대체하지 않습니다.
